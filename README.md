# Umakite Studio — Financial Dashboard

Dashboard keuangan realtime untuk Umakite Studio, terhubung ke Google Sheets via Apps Script.

## Setup

1. Deploy `umakite_apps_script.gs` ke Google Apps Script
2. Buka dashboard → klik **⚙ Sumber Data** → paste URL Apps Script
3. Dashboard auto-refresh setiap 5 menit

## Stack
- Vanilla HTML/JS/CSS — zero dependencies except Chart.js CDN
- Google Apps Script sebagai API backend
- GitHub Pages sebagai hosting
